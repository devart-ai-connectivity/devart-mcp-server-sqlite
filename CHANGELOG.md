# Changelog

## 1.1.0 - 2026-09-02

### Added

- Support for customizing the server's HTTP binding address.
- Support for defining a prefix for the server's HTTP paths.

### Changed

- Improved the syntax of the `config` command.

## 1.0.0 - 2026-05-20

### Added

- Initial release.
- Support for the Windows 32-bit and 64-bit platforms.
